How piers work

A tiny front desk

A Cloudflare Worker with one Durable Object per pier keeps the guest list, passes join requests to the host and relays WebRTC connection setup.

Files go peer to peer

Every browser on a pier connects directly to the others over WebRTC data channels. File bytes never touch the server.

Nothing is stored

The server keeps no files and no accounts. It remembers only that a pier code was used, so an old link can never lead to someone else's pier.

Host your own

You need Node.js and a Cloudflare account to deploy. Local development needs neither an account nor the internet.

  1. Get the code

    git clone https://github.com/OlutobiOgunsola/pierhop
    cd pierhop/web && npm install

  2. Run it locally

    Starts the website and the pier server at http://localhost:8787.

    npx wrangler dev

  3. Deploy

    Publishes to your Cloudflare account.

    npx wrangler deploy

Share a computer's folders over your own network

The PierHop app runs on a Mac or Linux machine and serves a page to every device on the same network. It suits a home or office: share whole folders, preview photos and video, and keep it running all day.

Install the app

Needs macOS or Linux with Python 3.9 or newer, and no other dependencies. Devices on the same network connect with a QR code.

Traffic on your network is plain HTTP, so use it on networks you trust.

  1. Install

    pipx install pierhop

  2. Run

    The control page opens in your browser. The first time, macOS asks whether Python may accept incoming connections: click Allow.

    pierhop

  3. Connect

    Scan the QR code on the control page with a phone, enter the PIN, and add files or folders.
